# Enriching Stock Market Data using OpenAI API

### This is one of my favorite projects I've completed through DataCamp. It significantly has improved my skills in API integration, data manipulation and AI-powered data analysis through python.

### In this project I've worked with two datasets , nasdaq100_CA.csv and nasdaq100_price_change.csv, to analyze Nasdaq-100 companies and their stock market performance.

### I first used pandas to load and combine datasets, incorporating YTD column indicating the the stock performance into the nasdaq100_ca DataFrame. I then integrated OpenAI API to classify each company to its corresponding sector, enriching the dataset with new sector column.

### Then I've made another OpenAI API request to analyze stock performance and identify the best two best performing sectors to recommend them and recommend two best companies from each sectors based on their YTD performance.

# Key Takeway

### This project has developed my understanding how large language models can be integrated real-world data workflows to enrich existing datasets and generate meaningful insights. It also has improved my ability to handle API responses and build practical AI-powered applications. Moreover, this project taught me the importance of being mindful of API usage when working with Large Language Models (LLMs). I learned that repeatedly executing API requests while debugging code can lead to rate-limiting errors, potentially interrupting development and requiring additional waiting time before making new requests.
